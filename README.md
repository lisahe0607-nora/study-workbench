# study-workbench

Nora 的学习工作台：学习中心、任务管理、学习记录与目标设置。

访问：https://lisahe0607-nora.github.io/study-workbench/

使用已有账号登录；同一账号可在电脑、手机和平板读取云端进度，暂不提供自助注册。学习中心可搜索和展开账号内的课程与章节目录，打开夸克继续学习。任务只需名称即可创建，科目与时间可选，不要求关联知识或资料。

旧浏览器体验版记录保留，可登录后在备份与恢复中导出、预览并手动导入。打开资料、完成任务与记录知识掌握分别处理。

此仓库仅保存审核后的静态网页和公开说明。账号、个人目标、网盘目录清单、学习数据与备份不在本仓库。
